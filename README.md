A simple programming language currently written in C# and C.

See [ROADMAP.md](ROADMAP.md) for the current native runtime roadmap.

## Project Layout

- `src/` contains the C# compiler pipeline.
- `native-jit/` contains the native C runtime, interpreter, heap, GC, and future JIT work.
- `output.cmm` is generated by the compiler and consumed by the native runtime.

## Common Workflow

Build the compiler:

```powershell
dotnet build
```

Generate `output.cmm`:

```powershell
dotnet run --no-build
```

Build the native runtime:

```powershell
cd native-jit
$env:PATH='C:\msys64\clang64\bin;C:\msys64\usr\bin;' + $env:PATH
cmake --preset clang64-debug
cmake --build --preset clang64-debug
```

Run the generated program:

```powershell
.\native-jit\cmake-build-clang64-debug\cmm_runtime.exe output.cmm
```

Build with AddressSanitizer and UndefinedBehaviorSanitizer:

```powershell
cd native-jit
$env:PATH='C:\msys64\clang64\bin;C:\msys64\usr\bin;' + $env:PATH
cmake --preset clang64-asan
cmake --build --preset clang64-asan
.\cmake-build-clang64-asan\cmm_runtime.exe ..\output.cmm
```
